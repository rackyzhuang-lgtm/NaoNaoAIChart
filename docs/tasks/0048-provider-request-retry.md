# 任务 0048：模型请求默认重试

- 状态：代码修改完成，定向验证通过
- 日期：2026-08-10

## 问题

切换 API Key 分组后，模型网关可能短暂返回 HTTP 503。原 renderer 请求层在收到 `ApiError` 后立即抛出，且默认重试次数为 3；模型 Provider 的 POST 请求还显式设置为单次请求，导致短暂故障直接显示错误。

## 修改

- 默认请求重试次数统一为 5 次（初次请求失败后再进行 5 次重试）。
- 任何非正常响应或网络异常都会重试；连续失败后抛出最后一次错误。
- 用户主动取消请求时立即停止，不因重试重新发起请求。
- Provider 的 POST 请求使用默认 5 次重试；确需单次请求的调用仍可显式传入 `retry: 0`。
- API 错误保留 HTTP 状态码，便于最终错误诊断。

## 验收标准

- [x] 503 后后续请求成功时，调用方收到成功响应。
- [x] 默认策略连续失败时总请求次数为 6（初次请求 + 5 次重试），随后才抛出错误。
- [x] 非 503 的非正常响应同样进入默认重试流程（请求层统一处理所有非 2xx 响应）。
- [x] AbortError 不会被重试。
