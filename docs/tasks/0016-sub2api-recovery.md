# 任务 0016：sub2api 异常恢复体验

状态：Done

## 目标

统一桌面账户能力在会话过期、断网、超时、限流和服务端功能关闭时的错误分类与恢复操作，避免局部请求失败清空仍然有效的账户数据。

## 范围

- 主进程区分网络断开、请求超时、HTTP 429、HTTP 403/404 与会话失效。
- IPC 仅向 renderer 传递白名单错误类别、HTTP 状态和有限重试信息，不传递令牌、响应正文或内部错误上下文。
- renderer 提供稳定的本地化提示与重试入口；会话失效时回到登录表单，局部功能失败保留其他账户数据。
- 为错误分类、refresh 失败清理和 renderer 恢复交互增加回归测试。
- 继续扫描并移除默认可达路径中的 Chatbox 托管网络调用和用户可见字眼，不破坏上游兼容数据读取。

## 验收

- 401/refresh 失败后主进程清理会话，账户页提示重新登录。
- 断网/超时显示可重试提示；429 显示限流与稍后重试建议；403/404 显示功能未开放提示。
- 任一账户子模块失败不清空当前用户与其他已加载模块数据。
- 定向测试、TypeScript、变更文件 Biome、生产构建和 `git diff --check` 通过。

## 完成记录

- 主进程新增网络、超时、限流、功能关闭、无效响应和会话失效分类；refresh 失败会清理对应会话代际。
- IPC 只传递白名单分类、状态码和受限 `Retry-After` 秒数；renderer 按分类提示并在局部失败时保留当前账户数据。
- 移除默认可达的托管 MCP、产品技能和 Chatbox Provider/云解析入口；旧配置读取兼容但映射到本地解析，未继续触发旧服务请求。
- 删除未使用的 Chatbox 网页解析调用，并将附件/文档解析错误文案改为通用提示。
- 定向 Vitest：7 个文件、54 项通过；TypeScript 通过；变更文件 Biome 无 error，仍有仓库既有 warning。
- 生产构建通过，产物位于 `release/app/dist`；E2E 脚本仍因缺失 Playwright 配置不可执行，未声称 E2E 通过。
