# 任务 0045：账户注册

- 状态：已实现并完成自动化验证；真实账号注册未执行。
- 日期：2026-08-10
- 关联 ADR：ADR-0015

## 目标

在账户登录入口旁提供注册功能，调用固定服务 `https://naonaoai.shop` 的公开账户接口完成邮箱注册和验证码确认。

## 实现范围

- 通过主进程调用 `POST /api/v1/auth/send-verify-code` 发送邮箱验证码。
- 通过主进程调用 `POST /api/v1/auth/register` 完成注册，成功后建立当前账户会话。
- 根据公开设置显示注册开关、邮箱验证开关和邮箱后缀限制。
- renderer 只通过窄 IPC 接收脱敏用户结果；密码和验证码不写入持久化存储。
- 验证码、验证码服务错误和不允许的邮箱域名使用中文界面提示。

## 验收标准

- [x] 登录旁显示“注册”，且 `registration_enabled=false` 时不显示注册入口。
- [x] 注册提交前校验邮箱、密码长度和服务端返回的邮箱后缀白名单。
- [x] 邮箱验证开启时可发送验证码，并以 6 位验证码完成注册。
- [x] 注册成功后账户页进入已登录状态，认证令牌不会返回 renderer。
- [x] 定向测试、TypeScript、Biome、`git diff --check` 通过。
- [x] 真实账号注册未执行，避免创建线上账户和发送验证码。
