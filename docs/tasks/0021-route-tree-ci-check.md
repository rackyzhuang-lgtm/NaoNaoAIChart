# Task 0021: Generate TanStack route tree before type checking

Status: Done

## Problem

`src/renderer/routeTree.gen.ts` is generated by the TanStack Router Vite plugin and intentionally ignored by Git. A clean GitHub Actions checkout ran `pnpm check` before the renderer build, so TypeScript could not resolve the generated module and inferred every `createFileRoute` path as `undefined`.

## Scope

- Add a repository script that generates the route tree with the locked `@tanstack/router-generator` dependency.
- Run route generation automatically as part of `pnpm check`.
- Keep the generated file ignored and uncommitted.
