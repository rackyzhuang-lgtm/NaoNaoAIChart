# ADR-0003：首发版本使用固定 sub2api 实例

- 状态：Accepted
- 日期：2026-08-05
- 决策者：项目所有者

## 背景

桌面端需要确定 sub2api 请求的服务根地址。可选方案包括允许用户填写任意实例，或由项目在构建中固定首发实例。

## 决策

1. 首发版本固定连接项目所有者部署的 `https://naonaoai.shop`。
2. 共享常量 `SUB2API_BASE_URL` 定义在 `src/shared/constants.ts`，作为后续账户控制面和模型网关适配的唯一基础地址来源。
3. 该 HTTPS 地址是公开产品配置，可以提交到仓库；JWT、refresh token、API Key、测试账号和其他秘密仍不得写死或提交。
4. 当前不提供任意 sub2api 实例的用户配置入口。以后如需支持多实例，新增 ADR 并设计配置迁移。

## 影响

- 客户端安装后无需用户填写服务地址，首次使用流程更短。
- 测试和发布必须验证固定域名的 HTTPS、证书、可用性与 API 兼容性。
- 域名迁移需要发布客户端配置变更；在服务端重定向或兼容期之外，旧客户端可能无法连接。

## 验证

- 类型检查和 lint 通过。
- 第二批契约测试从 `SUB2API_BASE_URL` 派生请求地址，不在各模块重复硬编码域名。
- 发布前验证生产域名只返回预期的 sub2api 服务，且不会把认证信息写入日志。
