# ADR-0015：桌面端账户注册边界

- 状态：Accepted
- 日期：2026-08-10

## 背景

NaoNaoAI Chat 需要让普通用户在账户页面注册，而不是依赖打开外部面板。固定服务的公开设置提供注册开关、邮箱验证开关和邮箱后缀白名单。

## 决策

- 注册请求只能由 Electron 主进程通过固定 `SUB2API_BASE_URL` 派生的 `/api/v1` 地址发起。
- renderer 通过显式 IPC 方法提交注册表单和请求验证码，不使用通用 IPC，也不直接跨域请求服务。
- 密码和邮箱验证码仅在当前表单及主进程请求生命周期内存在，不写入本地存储、URL、日志或测试 fixture。
- 注册成功后由主进程建立会话，只向 renderer 返回既有脱敏用户 DTO；access token、refresh token 不通过 IPC 返回。
- 邮箱验证或验证码服务开启而桌面端未实现对应验证组件时，界面必须明确提示无法在桌面端完成注册，不得绕过服务端校验。

## 后果

- 注册与登录共享现有主进程会话和错误脱敏机制。
- 邮箱验证开启时注册流程需要先发送验证码，再提交验证码完成注册。
- 真实线上注册和验证码发送不属于自动化测试范围。
