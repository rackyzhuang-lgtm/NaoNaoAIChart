# ADR-0031：无限画布 Agent 工具契约适配

- 日期：2026-08-13
- 状态：已接受

## 决策

在现有 NaoNaoAI 主进程 Agent 网关中实现无限画布工具契约。高层节点工具在主进程转换为现有 `canvas_apply_ops` 请求，由 iframe 继续执行并对写操作进行二次确认。

## 理由

复用当前 NaoNaoAI 的 API Key、SSE、回执和画布模型调用链，避免引入额外登录凭证、本地服务或在线运行依赖。

## 边界

仅迁入公开工具 schema、参数校验、快照压缩和操作转换；不引入 Codex app-server、站点级 workbench 工具或服务端行为变更。画布写操作仍必须经过现有确认事件。
