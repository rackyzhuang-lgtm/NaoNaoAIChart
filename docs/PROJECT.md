# 项目说明

## 当前状态

截至 2026-08-05，仓库已导入 Chatbox Community Edition 基线 `f90fc31afd634494bdf8f074eca3e38fcf8da740` 并保留完整历史。第一批完成 Windows 基线验证；第二批完成 `NaoNaoAI Chat` 品牌基线、sub2api 控制面契约、主进程内存会话/HTTP client、窄业务 IPC、真实登录联调和 Windows x64/arm64 开发验收包。账户 UI、API Key 管理与模型 Provider 尚未实现。

## 产品目标

基于 Chatbox 二开一个桌面 AI 工作客户端：用户安装后，通过 HTTP API 连接项目所有者已经部署的 sub2api 服务，在同一应用内使用模型，并完成普通用户日常需要的账户与消费管理操作，减少访问 sub2api Web 控制台的频率。

目标不是把两个现有 Web/桌面界面简单拼接，也不是再次部署 sub2api，而是在 Chatbox 的桌面体验中通过接口实现经过权限约束的 sub2api 用户控制面。

## 目标用户

- 文职工作者：问答、文档处理、总结和日常办公。
- 新媒体从业者：内容生成、改写、素材和多模态任务。
- 程序员：代码问答、模型切换、工具调用和用量管理。
- 其他互联网相关工作人员：跨模型日常生产力工作。

## 功能范围

### 核心范围

- 使用项目固定的 sub2api 服务地址；当前不向用户开放任意实例配置。
- 普通用户登录、退出、刷新会话；注册是否开放由服务端公共设置决定。
- 处理需要的验证码、2FA 和外部 OAuth 流程。
- 查看用户概览、额度、订阅、用量趋势和错误请求。
- 创建、查看、编辑、启停和删除自己的 API Key。
- 将选定 API Key 自动配置到 Chatbox 的 sub2api Provider。
- 获取可用渠道、模型列表并执行聊天、Responses、图片等服务端实际开放的模型能力。
- 查看订阅与订单，发起支付、兑换码和退款申请等普通用户操作。
- 维护个人资料、安全设置、通知邮箱和账户绑定。
- 查看公告、渠道状态及用户可见的监控信息。
- 批量图片等扩展任务按独立阶段接入。

### 明确不做

- iOS、Android。
- sub2api 管理员控制台和管理员 API。
- 将 sub2api 后端打包进桌面安装包。
- 替换、重新部署或修改现有 sub2api Web/后端。

### 待确认范围

- Chatbox 的 Web 构建是否继续维护，还是仅保证桌面构建。
- 是否需要普通用户注册，还是仅允许已有账号登录。
- 支付方式的优先级，以及外部浏览器/二维码是否可接受。
- “所有普通用户功能”是否包含推广返利、Passkey、通知邮箱、渠道监控和批量图片。

## 成功标准

- 首次安装后，用户只需配置服务地址并完成一次登录。
- 后续启动可以安全恢复会话；令牌失效时能刷新或明确要求重新登录。
- 用户能在应用内创建/选择 API Key，并立即用于 Chatbox 模型调用。
- 常用账户操作无需重新打开 sub2api Web 控制台。
- 客户端不会获得或暴露管理员权限。
- 断网、服务升级、令牌过期、支付回调失败等状态有明确恢复路径。
- Windows、macOS、Linux 的构建和关键流程测试通过后才发布。
